Process description

Work item: an application or a prior authority that appears in the active work list.

Assignment version: the number used to check an assignment change.

  1. An application enters the list when it is ready for manual assessment. A prior authority enters the list when it is submitted.
  2. The work-list event processor creates a read-model row. The row contains the item ID, item type, submission time, and versions.
  3. The client sends GET /api/v0/work-list. The service checks caseworker access and reads the work-list projection.
  4. The service filters and sorts the results. It returns the oldest submission first, with item type and ID as additional sort fields.
  5. To assign an item, send POST /api/v0/work-list/{itemId}/assign. Supply expectedAssignmentVersion from the item last read.
  6. The service takes the assignee ID from the authenticated user's Entra OID. The request body cannot select another assignee.
  7. The service reads the durable work-item route. It sends the command to the application or prior-authority aggregate. It does not use the work-list projection to route the command.
  8. The aggregate checks the assignment version and current assignment. A stale version or an already assigned item causes a conflict. Successful assignment stores WorkItemAssigned.
  9. To remove an assignment, send POST /api/v0/work-list/{itemId}/unassign with the current assignment version. Successful unassignment stores WorkItemUnassigned. An already unassigned item causes a conflict.
  10. The command commits and returns 200 OK. A separate event processor applies the assignment change to the work-list row.
  11. A decision event removes its work-list row. An application decision removes only the application row. A prior-authority decision removes only the prior-authority row.
  12. The next GET reflects the change after the projection processes the event. A conflict does not cause the service to retry the assignment automatically.

Open list

unassigned=true and assignedToMe=false are the defaults. Use itemType to select applications or prior authorities.

Personal list

Use assignedToMe=true and unassigned=false. Set both to true to include personal and unassigned work. They cannot both be false.

Pages and changes

Pages start at 1. The default page size is 20; the maximum is 100. Assignment does not directly replace another assignee. Remove the assignment before a new assignment.
